# AI 법률 상담 서비스 웹사이트 기획안

## 1. 서비스 개요

**컨셉**: AI 챗봇이 초기 법률 상담(법률정보 안내 및 문제 유형 파악)을 실시간으로 제공하고, 필요 시 실제 변호사 상담으로 연결하는 서비스형 웹사이트

**타겟 사용자**
- 법률 문제가 생겼지만 어디서부터 시작해야 할지 모르는 일반인
- 간단한 법률 정보를 빠르게 확인하고 싶은 사용자
- 변호사 상담 전에 사전 정리가 필요한 사용자

**핵심 가치 제안**
- 24시간 언제든 즉시 응답
- 상담 전 심리적 진입장벽 완화
- 실제 변호사 상담 전 효율적인 사전 스크리닝

---

## 2. ⚠️ 가장 먼저 확정해야 할 법적 리스크 (매우 중요)

AI 법률 상담 서비스를 만들기 전에 반드시 짚어야 할 지점입니다.

### 변호사법 관련 이슈
- 한국 변호사법 제109조는 **변호사가 아닌 자의 법률사무 취급**을 금지합니다. AI가 구체적 사건에 대해 "이렇게 하면 이깁니다", "위자료 얼마 받을 수 있습니다" 같은 **개별 사안에 대한 법률 자문(legal advice)**을 하면 위법 소지가 있습니다.
- 반면 **일반적인 법률 정보 제공**(예: "이혼 절차는 이렇게 진행됩니다", "관련 법 조항은 이렇습니다")은 통상 허용되는 영역으로 봅니다.
- **따라서 서비스 설계 단계에서 AI의 역할을 명확히 규정해야 합니다:**
  - ✅ AI = 법률 정보 안내 + 상담 유형 분류 + FAQ 답변 + 변호사 매칭
  - ❌ AI = 개별 사건에 대한 승소 가능성 판단, 구체적 법적 조언, 서류 대필

### 필수 반영 사항
1. **면책조항(Disclaimer)**: 모든 AI 답변 하단에 "본 답변은 일반적인 법률 정보이며 법률 자문이 아닙니다"를 상시 노출
2. **실제 변호사 검수 체계**: AI 답변을 무인으로 완전 자동화하기보다, 실명 변호사가 소속되어 있고 최종 상담은 사람이 개입하는 구조 권장
3. **변호사 정보 명시**: 광고 규정상 소속 변호사 이름, 소속 로펌, 변호사 등록번호 등을 명확히 표기 (대한변호사협회의 변호사 광고에 관한 규정 준수)
4. **개인정보처리방침**: 상담 내용(민감정보 포함 가능)을 다루므로 개인정보보호법에 따른 처리방침, 동의 절차 필수

> 이 부분은 실제 서비스 오픈 전 변호사 자문을 통해 최종 검토받으시길 권장드립니다. 기획안에는 리스크를 최소화하는 구조로 반영하겠습니다.

## 3. 사이트 구조 (Information Architecture)

```
홈 (메인)
├── AI 법률 상담 (핵심 기능)
│   ├── 챗봇 상담 화면
│   └── 상담 유형 선택 (이혼/상속/부동산/노동/형사/계약 등)
├── 서비스 소개
│   ├── 이용 방법 (How it works)
│   └── AI 상담의 한계 및 안내
├── 변호사 소개
│   └── 소속 변호사 프로필, 전문분야
├── 법률 정보 아카이브 (블로그/FAQ)
├── 상담 신청 (실제 변호사 연결)
│   └── 예약 폼 / 연락처
├── 요금 안내 (무료 AI 상담 + 유료 정식 상담 등)
└── 하단: 이용약관 / 개인정보처리방침 / 광고 표기사항
```

## 4. 페이지별 상세 구성

### 4-1. 메인 페이지
- 히어로 섹션: 핵심 카피 + "AI 상담 시작하기" CTA 버튼
- 상담 가능 분야 아이콘 그리드 (이혼, 상속, 형사, 부동산, 노동, 계약 등)
- AI 상담 프로세스 3단계 시각화 (질문 입력 → AI 분석 → 변호사 연결)
- 신뢰 요소: 소속 변호사 이력, 상담 건수, 이용 후기
- 면책조항 배너 (눈에 띄게, 숨기지 않고)

### 4-2. AI 챗봇 상담 화면
- 채팅 UI (사용자 입력 / AI 응답 말풍선)
- 상담 시작 시 자동 안내 메시지: 법률정보 제공 목적임을 고지 + 동의 체크
- 답변마다 "이 답변은 법률 자문이 아닙니다" 표시
- 상담 종료 시 "변호사와 직접 상담하기" 유도 버튼
- 상담 내용 요약 후 변호사에게 전달하는 흐름(선택 시)

### 4-3. 변호사 소개
- 실명, 사진, 변호사 등록번호, 주요 경력, 전문분야
- (AI가 아닌 실제 사람이 있다는 신뢰 확보 목적)

### 4-4. 법률 정보 아카이브
- SEO 목적 + 신뢰도 확보용 콘텐츠
- 카테고리별 법률 가이드 글

### 4-5. 상담 신청/연락처
- 폼: 이름, 연락처, 상담 분야, 간단 내용, 개인정보 동의 체크박스
- 카카오톡 채널 연동, 전화, 이메일 등 채널 다양화

## 5. AI 챗봇 기능 설계 방향

| 항목 | 방향 |
|---|---|
| 답변 범위 | 일반 법률 정보, 절차 안내, 유사 사례 유형 분류까지만 |
| 톤앤매너 | 공감적이면서도 전문적, 과도한 확신 표현 지양 |
| 이스케이프 로직 | 구체적 자문 요구 시 "변호사 상담이 필요합니다"로 자연스럽게 전환 |
| 로그 저장 | 상담 이력 저장(암호화) → 변호사 인계 시 활용 |
| 언어 | 한국어 기본, 필요 시 영어 지원 |

## 6. 디자인 방향

- **톤**: 신뢰감 있고 차분한 느낌 (로펌 특유의 권위 + AI 서비스의 친근함 균형)
- **컬러**: 딥네이비/차콜 + 포인트 컬러(골드 또는 블루 계열) — 법률 산업에서 흔히 쓰는 신뢰색
- **타이포그래피**: 명조 계열 헤드라인(전통/신뢰) + 고딕 계열 본문(가독성)
- **UI 특징**: 챗봇 인터페이스가 핵심이므로 채팅 UX에 공을 들여야 함

## 7. 기술 스택 제안

| 영역 | 옵션 |
|---|---|
| 프론트엔드 | React (or Next.js) |
| 챗봇 엔진 | Claude API 등 LLM 연동 + 시스템 프롬프트로 답변 범위 제한 |
| 백엔드 | Node.js/Express 또는 서버리스(예: Vercel Functions) |
| 데이터 저장 | 상담 로그 DB (암호화 저장, 개인정보 분리 보관) |
| 호스팅 | Vercel / Netlify (빠른 배포) |

## 8. 개발 단계 로드맵

1. **1단계**: 정보구조 확정 + 와이어프레임
2. **2단계**: 법률 자문(면책조항, 광고 규정 준수) 확정
3. **3단계**: 정적 페이지 제작 (메인, 소개, 변호사, 연락처)
4. **4단계**: AI 챗봇 프로토타입 구현 (시스템 프롬프트로 답변 범위 통제)
5. **5단계**: 실제 변호사 연결 플로우 및 폼 연동
6. **6단계**: 테스트 및 오픈
